# Crab Defender

A 2D underwater adventure game built with Flutter and Flame where you play as a brave crab defending its home against a variety of ocean enemies.

![Game Screenshot](assets/images/screenshots/Ekran%20Resmi%202025-04-30%2015.40.16.png)

## Game Overview

Crab Defender is an action-packed survival game set in the depths of the ocean. Control a determined crab as it battles against various marine creatures including fish, octopuses, sharks, jellyfish, starfish, and more. Each enemy has unique behaviors, movement patterns, and attack strategies.

## Features

- **Diverse Enemies**: 9 different enemy types, each with unique behavior patterns and abilities
- **Combat System**: Attack with your crab's claws using the space key
- **Trap Placement**: Tap the screen to place traps that damage enemies
- **Health System**: Manage your health points while fighting waves of enemies
- **Score System**: Earn points by defeating enemies, compete for high scores
- **Beautiful Visuals**: Underwater-themed graphics and animations
- **Responsive UI**: Clean menu interface and gameplay HUD

## Enemy Types

- **Fish**: Fast but weak enemies
- **Octopus**: Strong and durable with complex movement patterns
- **Crab Enemy**: Defensive enemy with damage reduction abilities
- **Jellyfish**: Can electrify and deal area damage
- **Seahorse**: Can teleport and cloak itself
- **Shark**: Powerful enemy that charges at the player
- **Pufferfish**: Can inflate and explode
- **Stingray**: Fast dives and leaves damaging trails
- **Starfish**: Can attach to the player, split into smaller enemies, and drop poison

## Technical Details

- Built with **Flutter** for cross-platform compatibility
- Utilizes the **Flame game engine** for optimized 2D rendering
- Component-based architecture for easy extension
- Collision detection system for interactive gameplay
- Game state management for seamless transitions between screens

## Controls

- **Left/Right**: Move with arrow keys or A/D keys
- **Attack**: Press Space key
- **Place Trap**: Tap on the screen
- **Pause**: Click the pause button or press ESC

## Installation

1. Make sure you have Flutter installed
2. Clone this repository
3. Run `flutter pub get` to install dependencies
4. Connect a device or emulator
5. Run `flutter run` to start the game
